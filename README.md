# 305201 Learning Activities

เว็บกิจกรรมการเรียนรู้แบบ instructor-guided สำหรับวิชา 305201 Soft Skill 3:
Engineering Teamwork, มหาวิทยาลัยนเรศวร

## การใช้ในชั้นเรียน

- ผู้สอนเปิดหน้า index.html จากเครื่องหลักหรือจอฉาย
- เลือกหัวข้อ แล้วใช้ปุ่ม phase control เพื่อเปิด Check-in, เกม, Debrief และ Exit ticket
  ตามจังหวะการสอน
- ผู้เรียนร่วมอภิปรายและทำงานเป็นทีมโดยไม่ต้องเข้ามาใช้งานเว็บไซต์
- ลิงก์ที่ใส่ ?mode=student เป็นมุมมองสังเกตซึ่งซ่อนตัวควบคุมและช่องกรอกข้อมูล

ทุกหัวข้อใช้โครงเวลา 60 นาที: Check-in 5 นาที, Mini-lesson 10 นาที, Game 35 นาที,
Debrief 5 นาที และ Exit ticket 5 นาที

## Topics

มี 15 หัวข้อ ครอบคลุม teamwork, communication, feedback, self-management,
transparent work, psychological safety, risk, meeting facilitation, escalation,
uncertainty, inspect-adapt, retrospective, integration, peer review และ final showcase

## Deployment

เมื่อ workflow Deploy GitHub Pages ทำงานจาก branch main เว็บไซต์จะเผยแพร่ผ่าน GitHub Pages
ของ repository นี้
